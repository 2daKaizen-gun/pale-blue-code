# Phase 9-B PRD — 울타리 열기 (Opening the Gate)

> *작성일: 2026-07-09*
> *상태: **완료 (2026-07-16)** — sub-9B-1·2·3 전부 종료, Phase 9-B 닫힘. 인계: `docs/phase-handoffs/phase-9B-to-9C.md`*
> *전신(前身): `docs/specs/phase-9/9B-PLAN.md` (계획 초안) 를 정식화한 문서*

> 🛰️ 트랙 "모두의 하늘"의 **둘째 악장**. 9-A(Vetting)가 **신호를 심문하는 법**을 벼렸다면,
> 9-B는 그 판별기를 손에 쥐고 **진짜로 아무도 기록하지 않은 하늘을 사냥한다.**
> Phase 9 PRD §5가 "판별기가 진짜/가짜를 가릴 수 있게 된 *다음에* 사냥터를 넓힌다"고
> 미뤄둔 바로 그 악장이다.

---

## 1. 한 문장 요약

**판별기가 진짜/가짜를 가릴 수 있게 되었으니, 이제 KOI 카탈로그에 *없는* 별을 실제로 사냥해 — 우리 손으로 걸러낸 "신뢰도 있는 새 후보"를, 혹은 정직한 빈손을, 판별의 창과 함께 내놓는다.**

---

## 2. 동기 (Why)

9-A는 "이 신호를 믿어도 되는가?"에 답하는 칼을 만들었다. 그러나 그 칼로 심문한 대상 — 현재 Hunt의 큐레이션 5개 타깃 — 은 **전부 이미 알려진 KOI**였다. 교육용으로는 정직하게 재라벨했지만(9-A 청산), 그것은 여전히 *"알려진 답과 대조하는 시연"*이지 **발견**이 아니다.

2026-07-07, 판별 리포트를 붙이고 실물을 확인하던 중 권이건이 물었다:

> *"이미 발견된 행성 말고, 우리가 직접 찾는 걸 원하는데."*

그래서 미검증 타깃 `KIC 10583180`을 라이브로 완주했고, 우리 4관문이 독립적으로 **UNLIKELY(2차 식 HARD → 쌍성)** 판정 → NASA도 **K00748.01 FALSE POSITIVE**. 엔진은 정직했다. **그러나 타깃이 정직하지 않았다** — 알려진 KOI를 "논쟁 중"으로 포장한 연출이었다.

Phase 8이 *"찾을 수 있는가?"*, Phase 9-A가 *"믿어도 되는가?"* 였다면, **Phase 9-B는 "그럼 진짜로 찾으러 가자"** 이다. 심문법을 벼렸으니, 이제 **답을 모르는 별**로 간다.

---

## 3. 정직한 못 3 — 사냥터도 정직해야 한다

이 트랙은 못 1(목표는 "확정"이 아니라 "신뢰할 만한 후보")·못 2(방법은 NASA와 같아 믿을 수 있다) 위에 섰다. 9-B는 **셋째 못**을 박고 간다.

### 못 3 — "우리가 직접 찾았다"고 말하려면, 그 별이 실제로 아무도 기록하지 않은 별이어야 한다

> 🌌 **알려진 KOI를 미확인처럼 포장해 "발견"의 느낌을 주는 것은 판별의 정직함을 배신한다.**
> 진짜 단독 사냥 = **KOI 카탈로그에 항목이 아예 없는 KIC**를 훑고, 우리 판별기로 거른다.
> 9-A의 청산이 "판별은 정직했으나 사냥터가 가짜였다"를 고쳤다면, 9-B는 처음부터 **정직한 사냥터**를 짓는다.

### 정직한 기대치 — 개척지는 대부분 빈손이다

낭만을 팔지 않는다. 케플러의 밝은 별들은 NASA가 이미 샅샅이 훑었다. KOI에 없는 별은 십중팔구 **transit 신호 자체가 없다**(그래서 아무도 안 건드렸다). BLS는 노이즈에서도 "최우선 주기"를 뱉지만, 우리 4관문이 대부분 걸러낼 것이다.

> **개척지의 진실: 대부분 빈손, 아주 드물게 진짜.** 그리고 그 드문 "strong + KOI에 없음"이 나오는 순간 — 판별의 창이 그것을 신뢰 있게 만든다. **빈손조차 정직한 결과다: "여기엔 행성이 없다"도 과학이다.**

---

## 4. 사용자 시나리오

### 주요 경로 — 아무도 안 간 하늘로

1. **타깃 선택** — 두 방식:
   - *무작위 미기록 KIC* 버튼 → KOI에 없는 케플러 관측 별을 하나 뽑는다.
   - *자유 입력* → 사용자가 KIC 번호를 직접 입력(HuntPage에 이미 있는 경로를 1급 시민으로 승격).

2. **KOI 대조 먼저** — 고른 별이 카탈로그에 있는지 즉시 확인:
   - 있으면 → *"이건 이미 기록된 천체입니다"* (사냥 대상 아님 — 정직하게 표시하고 다음으로).
   - 없으면 → **미기록 확정.** 진짜 사냥 진입.

3. **LC → BLS → 4관문 판별** (9-A 엔진 그대로) → trust로 분기:
   - `strong` → ★ *"우리가 찾은 신뢰 후보"* (드묾. 발견기록 v2가 판별 근거와 함께 담는다).
   - `weak` → *"애매 — 추가 검토 필요."*
   - `unlikely` → *"빈손/노이즈/쌍성 — 여기엔 행성이 없습니다. 그것도 답입니다."*

4. **정직한 집계** — 사냥 횟수·빈손 횟수를 숨기지 않고 노출: *"37번 사냥, 후보 0 — 개척은 원래 이렇다."*

### 기억에 남길 한 순간

> 무작위 버튼을 눌러 아무도 기록하지 않은 별을 처음 열고, 빈손을 받아든 순간.
> *"아, 개척은 이런 거구나. 그리고 이 빈손도 거짓이 아니라 진짜 결과구나."*
> 그리고 언젠가, 아주 드물게 — strong이 뜨는 순간.

---

## 5. 범위

### ✅ 포함

1. **진짜 사냥 모드 (교육 데모와 분리)** — 현재 큐레이션 헌트와 **별도 페이지/모드**. 둘을 섞으면 "시연"과 "발견"의 경계가 흐려져 못 3을 다시 어긴다.

2. **타깃 선정** — (c) 자유 입력 승격 + (a) "무작위 미기록 KIC" 추출. *KOI에 없는 KIC 풀을 어떻게 얻는가*는 TechSpec의 핵심 결정 사항.

3. **미기록 판정** — `koi_check`(9-A/8 재사용)로 "KOI에 있음/없음"을 먼저 갈라, 사냥 대상 여부를 정직하게 표시.

4. **결과 분기 UI + 정직성 규칙** — trust별 분기(§4.3) + 빈손을 실패 아닌 결과로 제시 + 사냥/빈손 횟수 노출.

5. **재사용** — 9-A 판별 엔진(`vetting.vet`)·리포트 카드(`VettingReportCard`)·발견기록 v2(`discovery@2`)를 **그대로**. 9-B는 이들을 감싸는 새 흐름이지 새 판별이 아니다.

### ❌ 제외 (다음 악장으로)

- **TESS 편입** — 별도 데이터 파이프라인. Kepler로 먼저 정직한 사냥을 완성한다.
- **픽셀 수준 진단 (centroid, difference imaging)** — target pixel file 필요. 4관문 이후의 고급 단계.
- **사용자 계정 / 발견 저장소 / 커뮤니티** — 트랙의 마지막 악장 9-C "모두의 발견".
- **NASA TCE 아카이브 직접 질의** — 접근·범위 부담.

## 6. 성공 기준

### 정성적

- KOI에 없는 KIC를 실제로 돌려 **정직한 결과**(대부분 빈손)를 낸다.
- 빈손이 **실패가 아니라 결과**로 느껴진다 — 사용자가 낙담이 아니라 *"개척은 이런 거구나"* 를 배운다.
- 교육 데모와 진짜 사냥이 UI에서 **명확히 구분**된다 (못 3).

### 정량적

- **미기록 판정**: KOI에 있는 KIC 입력 → "이미 기록됨" 표시 / KOI에 없는 KIC → 사냥 진입. 라이브 검증.
- **무작위 미기록 추출**: 뽑힌 KIC가 (i) 케플러 관측 데이터 존재 (ii) `koi_check` 결과 빈 배열 — 둘 다 충족.
- **strong + 미기록**이 나오면 발견기록 v2가 4관문 근거 + trust와 함께 담는다.
- **`npm run build` + `pytest` 통과**: 매 커밋.

---

## 7. 비기능 요구사항

- **판별은 순수 계산·9-A 그대로** — 새 판별 로직 0. 9-B는 타깃 선정 + 흐름 + 정직성 UI만 추가.
- **미기록 판정은 로컬** — `koi_catalog.csv` 대조(새 외부 API 없음). 무작위 추출의 "관측 데이터 존재" 확인만 lightkurve 프로브 필요(TechSpec에서 방식 확정).
- **정직성 UI 규칙(9-A 계승)**: "확정/확인된 행성" 단정 금지. 빈손은 실패 아닌 결과. "발견" 단어는 strong+미기록에만, 그것도 "후보"로만.
- **manualChunks 순서**: `@react-three` → `/three/` 절대 변경 금지.
- **분리 원칙**: 진짜 사냥은 교육 데모와 별도 진입점 — 경계를 흐리지 않는다.

## 8. 천문학 — Phase 9-B에서 배우는 것

| 개념 | 설명 |
|------|------|
| KOI 카탈로그의 경계 | KOI = Kepler Object of Interest. 카탈로그에 *없다*는 건 "아무도 후보로 올리지 않았다"는 뜻 — 대개 신호가 없어서다. |
| 개척지의 통계 | 밝고 신호 강한 별은 이미 다 훑혔다. 미기록 별의 절대다수는 빈손 — 이것이 실제 시민 과학의 일상. |
| 빈손의 과학적 가치 | "여기엔 행성이 없다"도 정보다. 과학은 배제(exclusion)로 전진한다. Null result는 실패가 아니다. |
| 검출 편향 (selection bias) | 자동 파이프라인은 단주기·깊은 transit에 최적화 — 장주기·저S/N은 아직 발견 대기. 개척의 틈은 여기 있다. |
| 독립 사냥의 의미 | 같은 아카이브, 독립 알고리즘, 아무도 안 본 별 — 우리가 도는 순간 그것은 그 별의 *첫 번째 판별*이다. |
