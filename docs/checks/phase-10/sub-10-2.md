## Scope

Phase 10 honesty nail 4 — *a wide sky is seen shallowly*. TESS watches ~85% of the
sky but only ~27 days per sector, so the four gates (which rest on repeated
transits) can be blunt. Rather than hide this, the backend now **measures** it and
**downgrades confidence** to match, without touching the gate math or the verdict.

Three Lights:

- **Light 1 — provisional-strong core** (`d85bf36`): `build_report` records
  `baseline_days = time[-1]-time[0]` (mission-agnostic), `transit_count =
  floor(baseline/period)`, `mission`, and sets `provisional = strong AND
  transit_count < _N_MIN_TRANSITS`. Pure helpers `transit_count()` /
  `is_provisional()`. `VettingReport` gains `mission`, `baseline_days`,
  `transit_count`, `sector_count`, `provisional` (all defaulted → backward
  compatible with cached Phase-9 reports).
- **Light 2 — sector threading** (`04fb973`): `hunt.lc_sector_count` reads the
  sectors recorded at fetch time from the cached TESS payload; `vet()` passes it
  into the report. Kepler → None; missing/corrupt cache → None (never guesses).
- **Light 3 — LC-response exposure** (`a6212bd`): `HuntLCResponse` carries
  `mission`/`baseline_days`/`sector_count`; the Kepler payload is extracted into
  `_build_kepler_payload` (sibling of `_build_tess_payload`) so both missions
  record baseline; the router maps only present keys so pre-Phase-10 caches fall
  back to defaults.

**The gate math and the `trust` verdict are untouched.** `provisional` is a
separate flag; `weak`/`unlikely` are never downgraded.

## The threshold (`_N_MIN_TRANSITS = 5`)

The physically honest driver is the number of transit epochs the gates actually
saw, `floor(baseline / period)`:

- odd/even compares odd- vs even-numbered transits — it needs **at least 2**, and
  is only robust with several (the engine already *holds* the gate below
  `_MIN_PTS=5` points per parity group).
- secondary needs enough phase coverage to trust a non-detection.

Five is deliberately conservative: a hot Jupiter (P≈3 d) in one 27-day sector gives
~9 transits and stays fully `strong`; a P≈7 d planet gives ~3–4 and becomes
*provisional*; a P≈13 d planet gives ~2. Kepler's multi-year baseline clears the
bar for essentially any detectable period, so nail 4 is universal in code but only
*bites* on short-baseline TESS — exactly its intent. The value is provisional and
will be revisited against a real TESS light curve in sub-10-3's live E2E.
