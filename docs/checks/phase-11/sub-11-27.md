## Why this, now

Path A's four sensitivity levers are all null (sub-11-23/24/25): the pipeline cannot lower these
floors, so the way to more Earth-size-sensitive targets is *more quiet dwarfs*, not a sharper eye
(vision §9-2). Sectors 103/104/105 are fully searched, and only ~6% of even carefully-chosen dwarfs
turn out quiet enough to reach Earth size — so a blind fetch marathon is wasteful. The question that
opens widening: can we predict, from catalog values we already have, which unsearched star will reach
Earth size, and spend the slow fetch there first?

## The predictor, and its measured limit

`scripts/predict_earth_reach.py` fits `log(floor) = a + b·Tmag` from the stars we have already
searched (measured floor + catalog Tmag), then ranks an unsearched pool by predicted minimum planet
radius (`sqrt(predicted_floor)·R★`). On our real searched set:

```
fit: log(floor) = -9.58 + 0.366·Tmag   (n=179, in-sample R^2 = 0.172)
held-out skill (train 90 / test 89): Earth-size precision 1.00 · recall 0.25 · median |err| 2.02 R⊕
```

Brightness is a **weak, one-sided** predictor. It explains only ~17% of the floor, because a low
floor comes from a quietness — red noise, crowding, stellar variability — that no catalog value
foretells. When it predicts Earth-size it is right (precision 1.00), but it misses three quarters of
the Earth-size stars (recall 0.25). So it is a pre-filter that says *where to look first*, never a
replacement for searching. The tool reports this skill itself, so the claim cannot drift.

## The first new sky — TESS sector 102

Built a 100-dwarf sector-102 pool (R 0.18–1.27 R☉, absent from TOI), then fetched and searched a
first batch of 8 (10 now carry a measured floor, two shared with earlier sectors):

```
sector 102 (10 searched of 100):  3 quiet · 5 insignificant · 2 rejected · 0 candidates
reaches Earth size:               1 of 10  — TIC 107548305, measured 0.87 R⊕ (floor 0.0020)
rejected (gates earned their keep):  TIC 238831201 sig 9.12 (symmetry) · TIC 1508739556 sig 16.24 (edge+symmetry)
```

No candidate — the two significant dips were both caught as instrument artifacts by the shape gates,
the same signature the pool sweeps kept finding. But widening did its job: **one new Earth-size-
sensitive target**, TIC 107548305 (a 0.18 R☉ dwarf), now joins the dossier.

## The predictor, checked against the wild

The payoff is what TIC 107548305 says about the predictor. It was the predictor's *sharpest* pick but
predicted at **1.60 R⊕ — not Earth-size**. Its measured floor puts it at **0.87 R⊕ — Earth-size.**
The quiet dwarf beat its predicted floor, exactly the recall<1 failure the held-out test measured: a
positive prediction is trustworthy, but a non-positive is not a rejection. This is why widening still
searches the sharpest predicted targets rather than trusting the label — and it worked, turning a
"predicted miss" into a real Earth-size-sensitive star.

## Honest boundary

- The fit is over ~179 searched dwarfs from two pools; a different stellar population (giants, very
  faint targets) would fit differently. The relation is for path A's small bright dwarfs.
- "0 predicted Earth-size in sector 102" is a *pre-filter* statement, not a claim that none exist —
  and the batch already found one the filter missed. The predictor prioritizes; it does not conclude.
- One batch of 8 is a small sample; the sector-102 pool has 90 unsearched left. This is a start.
