## Scope — honesty nail 5

The four gates (odd/even, secondary, shape, size) ask whether a signal *looks*
planetary. None asks whether there is a real detection at all. sub-10-3 proved the
cost live: `TIC 7318157` passed **strong 4/4** on a BLS peak of power 0.0004 whose dip
lived almost entirely in the even epochs — a classic noise signature — because with
scatter that wide the odd/even difference was only 1.83σ.

sub-11-1 puts a **precondition** in front of the four gates: fold the transits, measure
the depth against the scatter *between* transits, and if the signal is not a real
detection, stop before vetting and report `insignificant`. It is a precondition, not a
fifth gate — a gate assumes there is something worth judging; the precondition can say
there is not. It is the prerequisite for the monotransit work (sub-11-2+): a single
transit has no repetition, so every judgment about it is a significance judgment.

- **L1 — measure** (`89edebe`): `scripts/measure_detection_significance.py` computes the
  candidate figures on the three anchors + the noise case and picks the threshold from
  the data.
- **L2 — precondition + model** (`354b747`): `detection_significance()` in
  `services/vetting.py`, wired into `build_report` after de-alias and before the gates;
  the `insignificant` trust state and `significance`/`significant` report fields.
- **L3 — render the verdict** (`6a9b2ac`): the `insignificant` branch in
  `FrontierVerdict`, `VettingReport`, and `huntLog` — "검출 아님", empty-handed but
  honest, no gate list.
- **L4 — significance on the passing verdict** (`d4c69d5`): the same number shown even
  when a signal clears the bar (TechSpec §4, "판별의 창"), so the verdict is not a black
  box.

## L1: the threshold is measured, not asserted

The first guess — SDE, the periodogram peak's height above its own noise floor — was
**overturned by the measurement.** SDE is a repeat-transit figure and is blind to a real
monotransit, exactly the TechSpec R3 caveat. What separates cleanly is the folded transit
depth measured against the scatter *between* transits (`snr_between`).


Read three things out of it:

1. **SDE does not separate.** `TIC 102029734`, a real single-transit anchor, scores SDE
   1.7 — *below* the noise case `TIC 7318157` at 5.5. And SDE puts the EB false positive
   `KIC 10583180` (39.7) above the real planet `KIC 9140402` (28.1). BLS rewards
   repetition, so a periodogram figure is genuinely weak on a monotransit and cannot tell
   real-but-unrepeated from noise.

2. **`snr_between` separates cleanly, for k ≥ 2.** Noise sits at 3.02–3.23 (the frontier
   false positive `KIC 2557393` and `TIC 7318157`); every real multi-transit signal at
   6.00 or above. The gap is real, so the threshold is **`_SIG_MIN = 4.0`** — sitting in
   it, measured, the way `_N_MIN_TRANSITS` was (5 → 8 in sub-10-3).

3. **The wrong denominator, for contrast.** `snr_white` divides by the in-transit *sample*
   count, treating ~108 correlated samples in one TESS transit as independent draws. It
   stays high on the noise cases (22.0, 11.8) — exactly the manufactured confidence
   sub-10-3's odd/even fix removed. We do not use it.

Detection is not vetting: the EB false positive `KIC 10583180` correctly **passes** the
significance precondition (`snr_between` 29.82 — it is a real dimming) and is then caught
as `unlikely` by the four gates. Significance asks "is it real"; the gates ask "is it a
planet". An eclipsing binary is a real detection.

## L2: where the precondition stands, and the held case

In `build_report`, after de-alias (so significance is measured at the same period the
gates use) and before the four gates. `detection_significance` collapses each
well-sampled transit to one depth and returns the t-statistic that the mean depth
exceeds zero, using the between-transit scatter as the error.

For fewer than two observed transits it returns `None` — **judgment held, not made.** A
lone transit has no transit-to-transit scatter, so a single-transit *noise* case is not
caught here; that is the honest boundary of what one can say without repetition, and
single-event significance belongs to sub-11-2+. This is why the monotransit anchor
`TIC 102029734` keeps its verdict rather than being stopped.

`insignificant` is a fourth `trust` value, not a lower rung of the existing three: it is a
different axis — `unlikely` means "vetted, looks like a binary", `insignificant` means
"there was nothing real to vet". The report carries `significance` (the number) and
`significant` (the bool, default `True` so legacy caches validate).

## Honest boundary (carried forward)

The precondition is calibrated on repeated transits (k ≥ 2). A single-transit noise case
is not caught — SDE cannot stand in for `snr_between` there (it does not separate), and
there is no between-transit scatter to measure. That is not a gap to patch; it is the
subject of sub-11-2+ (monotransit detection), where single-event significance is designed
from scratch. sub-11-1's threshold must not be aimed at a lone transit.

The pipeline now asks "is this a real detection?" before it asks "does it look like a
planet?" — the order astrophysical pipelines always use, the one we had skipped. The
threshold came from a measurement that overturned its own first guess (SDE out,
`snr_between` in), and the one visible change to a verdict is a noise peak that used to
say `strong` and now says nothing. That is the direction honesty runs: the tool says
less than it did yesterday.
