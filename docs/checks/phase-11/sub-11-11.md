## Scope

A survivor's epoch is in **BTJD** (`BJD_TDB − 2457000`), TESS's internal offset, and its depth is a
bare fraction. Neither is what an outside observer reads: every published ephemeris and every ExoFOP
entry is in **BJD_TDB**, and a follow-up photometrist measures depth in **millimagnitudes**. Two
pure conversions move the numbers into that frame:

```
epoch_bjd_tdb = t0_btjd + 2457000.0            (BTJD -> BJD_TDB; a frame change, not a measurement)
depth_mmag    = -2.5 * log10(1 - depth) * 1000  (fractional depth -> millimagnitudes; logarithmic)
```

Together with the duration (already in hours) and the earliest recurrence (sub-11-10), these are
exactly the fields a campaign needs to point a telescope. The north-star (§5.5–§6) names this the
last bridge — the point where *your* flag becomes something TFOP / ExoFOP can act on.

- **L1 — the physics** (`f2e3df2`): `epoch_bjd_tdb(t0_btjd)` and `depth_to_millimag(depth)`, pure,
  no I/O; `depth_to_millimag` returns `None` for a non-physical depth (`<= 0` or `>= 1`).

## The conversions are the observer's frame

**BJD_TDB, anchored on the offset.** BTJD is `BJD_TDB − 2457000`; adding the offset back recovers
the full Barycentric Julian Date in the TDB scale that every ephemeris uses. The test pins
`epoch_bjd_tdb(1500) == 2458500.0` and `epoch_bjd_tdb(0) == 2457000.0` (BTJD 0 is the reference
epoch itself). A frame change, exact.

**Millimagnitudes, anchored on the logarithm.** A photometrist reads a flux drop as a magnitude
change, `Δmag = -2.5 log10(1 - depth)`, times 1000 for mmag. It is genuinely logarithmic, not a
rescale: a 1% transit is ~10.9 mmag, a 0.1% transit ~1.09 mmag, and doubling the depth does *not*
double the mmag. The test pins `depth_to_millimag(0.01) ≈ 10.912`, monotonicity in depth, and
`None` for a non-physical depth (`<= 0` or `>= 1`, where the magnitude is undefined).

## A worked brief

For a 1%-deep, 0.4-day transit seen at `t0 = 1500 BTJD` (as on the sub-11-10 example survivor,
TIC 156004112, whose `P_min ≈ 119 d` gives an earliest recurrence of `2019-05-15`):

```
epoch    = 1500 + 2457000 = 2458500.0 BJD_TDB   (the transit itself falls on 2019-01-16)
depth    = -2.5 log10(0.99) * 1000 = 10.9 mmag
duration = 0.4 d * 24 = 9.6 h
earliest recurrence = 2019-05-15 (sub-11-10)
```

and the brief reads: *epoch BJD_TDB 2458500.0, depth 10.9 mmag, duration 9.6 h, a second transit
no earlier than 2019-05-15 — the same numbers in your frame; still a light-curve single-transit
candidate, the bounds one-sided.* Two more, to show the units track the signal:

```
t0 = 1710 BTJD, 2.0% / 0.3 d  ->  epoch 2458710.0 BJD_TDB,  21.9 mmag,   7.2 h
t0 = 1500 BTJD, 0.5% / 0.5 d  ->  epoch 2458500.0 BJD_TDB,   5.4 mmag,  12.0 h
```

## Why it is honest

- **A translation, not an upgrade.** The brief moves the same numbers into an observer's frame; it
  does not raise the claim. The copy carries the caveats with the numbers — "still a light-curve
  single-transit candidate (not a planet), the bounds one-sided" — so a hand-off can never read as
  a confirmed world. The test `carries the candidate and one-sided-bound caveats` pins that the
  string says `행성 아님` and `한쪽 경계`.
- **The frame is named where the number is.** The epoch is labelled `BJD_TDB` and the depth `mmag`
  in the brief itself; the `2457000.0` offset is a named backend constant. An observer reading the
  card never has to guess which time system or unit the number is in.
- **No number, no brief.** `depth_mmag` is `None` for a non-physical depth, and the brief returns
  `null` when the core observer numbers (epoch, depth) are missing, so the card omits the block —
  the same null discipline as the bounds it sits beside.

## Honest boundary (carried forward)

The brief is only a translation: it inherits every caveat of the numbers it reframes (the catalog
radius behind the bounds, the main-sequence and circular/central assumptions, the BTJD frame of
`t0`) and adds none of its own beyond the two conversions' exactness. What it does *not* do is make
a survivor a discovery — a BJD_TDB epoch and a millimagnitude depth are the *format* a follow-up
campaign reads, not evidence that the dip is a planet. It is the last step on our side of the
bridge: the flag, now in the observer's frame, ready to hand off. Confirmation still belongs to the
telescopes the north-star (§6) names — radial velocity, high-resolution imaging, statistical
validation — and the brief says so, in the same breath as the numbers.

And still: none of the 16 plausible dwarfs is fetched yet, so no survivor with a real brief exists
on the live tool today. The translation is built and tested; the sky it will describe waits on the
same single local run — `python ../scripts/fetch_plausible.py`, then a plausible dwarf's first
hunt. When one lands, its survivors will carry not just their least period, warmest case, and
earliest recurrence, but a follow-up brief in an observer's frame — a real flag, ready to hand off.
