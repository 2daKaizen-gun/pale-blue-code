## The first candidate — and why it is not a planet

Searching the second extension batch, TIC 326691903 surfaced an event that cleared all four
existing discriminators *and* the significance floor: sig 10.86, `candidate = True`. The first in
the entire hunt. Radical honesty demanded it be inspected before it was believed.

The raw light curve settles the question. The observation **opens** at t = 1657.127 already ~6 %
below baseline and climbs monotonically back to 1.0 over ~0.15 d — a textbook TESS segment-start
thermal-settling / scattered-light recovery ramp. The search found two events on that ramp:

```
t0 = 1657.177   depth 5.06%   sig 48.45   -> edge FAILED   (0.05 d from the segment start)
t0 = 1657.277   depth 1.13%   sig 10.86   -> passed all 4  ("candidate")   <- the ramp's tail
```

The deep spike at the very start dies to the **edge** gate. Its neighbour one duration (0.1 d)
later sits 0.15 d from the boundary — just past the edge clearance of `1.0 * duration = 0.1 d` — and
rides the recovering ramp to a 1.1 % apparent dip. It is the *same* systematic, not a transit.

Why the four gates missed it: **edge** measures only distance to a boundary, and 0.15 d clears it.
**symmetry** compares ingress to egress *within* the narrow window, where a slow ramp still looks
locally symmetric (its value was 0.44, under the 0.5 cut). **coherence** and **flare** have no
purchase on a smooth ramp. None of them asks the decisive question: *do the two out-of-transit
shoulders sit at the same flux?* A real transit rests on a flat local baseline; this dip rides a
step.

## The fifth discriminator: `baseline`

A real central transit is a depression against a flat baseline — the star's brightness just before
ingress equals its brightness just after egress. The new check compares the median flux in the two
out-of-transit shoulders, `t0 +/- [0.75, 1.75] * duration`, and rejects the event when they differ
by more than the depth itself:

```
step_ratio = |median(left shoulder) - median(right shoulder)| / depth      reject if >= 1.0
```

The threshold was **measured, not asserted** (`scripts/measure_baseline_step.py`), the same
discipline `_SIG_MIN_MONO` was set by. Clean transits injected into real quiet TESS curves — kept
only if the full chain recovers them, they clear significance, and they pass the other four gates —
step by at most **0.32 * depth** (n = 38, p99 0.31). The recovery ramp on TIC 326691903 steps by
**4.67 * depth**. `_BASELINE_STEP_MAX = 1.0` sits in the empty gap between them: ~3x above the
loudest clean transit, ~4.7x below the artifact. Shoulders that fall in a data gap (too few points)
yield no test and pass — the edge gate already guards true segment boundaries.

Under `mono-v2`, TIC 326691903 recomputes to:

```
t0 = 1657.177   sig 48.45   rejected   (edge)
t0 = 1657.277   sig 10.86   rejected   (baseline)   <- was the candidate
```

candidate -> **rejected**. Zero candidates stand.

## The cache had to be invalidated

`_MONO_CACHE_VERSION` was bumped `mono-v1 -> mono-v2`. This is the load-bearing discipline the vet
cache taught (a stale derived result passes the schema and lies): the discriminator set changed, so
every stored monotransit result across the pool is recomputed under the new gate rather than trusted.
`tally_hunt._disposition_from_cache` honours the same version tag, so the tally can only count
freshly-recomputed results. The whole fetched set was re-searched under v2 to refresh it.

## Honest boundary

This does not make a discovery — it *un-makes a false one*, which is the same work from the other
side. The hunt's first candidate was an instrument artifact the gates should have caught, and now a
principled, measured gate catches it. That is exactly the Phase-11 thesis: the machines (and our own
first gates) miss things, and the way forward is to understand *why* a false positive looks the way
it does and build the discriminator its physics demands. The shape gates are now a set of five, each
with a reason it can state. Zero candidates across the searched pool remains the expected texture of
an honest single-transit hunt over quiet stars.
