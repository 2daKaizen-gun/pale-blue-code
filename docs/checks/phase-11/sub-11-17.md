## What changed

The 50-dwarf pool (sub-11-14/16) was searched end to end with zero candidates. That is a complete
search, not an exhausted sky. Sector 104 has far more planet-size dwarfs than 50; `select_for_hunt`
keeps the smallest N. So the pool was rebuilt to take the next-smallest tier as fresh hunt targets.

- **`backend/data/frontier_seeds_tess.json`** — rebuilt at `--n 100` (sector 104). Still entirely
  planet-size (`assess_pool`: 100 plausible, 0 too big); the new stars are dwarfs of R★ 0.25–0.46 R☉,
  minimum detectable planet 1.7–3.1 R⊕ — the smallest reaching near-Earth sensitivity.
- **`.github/workflows/frontier-refresh.yml`** — the biweekly refresh now passes `--n 100`. Without
  this the default `n=50` would silently shrink the pool back on the next run and drop half the
  searched stars — the exact "silent churn" failure the tally was built to catch.
- **`test_pool_assessment`** — asserts on the live pool count (`>= 100`), still dwarf-dominant.

### The resample is honest about what it drops

`select_for_hunt` samples a seed-10 candidate pool whose size scales with `n`, so growing `n` is not
a strict superset: 48 of the searched 50 survive into the wider pool, 2 were dropped by the resample.
Their verdicts remain recorded in sub-11-16 — no searched star's result is lost, only its membership
in the *live* pool. `tally_hunt.py` reads the caches per star, so it reports exactly what is on disk:
48 of the old 50 as searched, plus the new batch.

## The first symmetry-only rejection

Across the first fifty dwarfs, every one of the seven significant single events sat on a segment
boundary and died to the **edge** gate (most also to symmetry). This batch produced the exception:

```
TIC 404030766   sig 41.26   failed: symmetry     (mid-segment asymmetric ramp)
```

It is the second-loudest event in the whole pool, behind only sig 61.99, and it is **not** an edge
artifact — it sits mid-segment, where the edge gate never fires. The **symmetry** gate caught it
alone: a real transit is very nearly symmetric about its midpoint, and a one-sided flux ramp is not.
This is the Phase-11 thesis sharpening: the shape gates are a *set*, not a single trick. A loud
systematic that does not ride a downlink boundary still fails because its *shape* is wrong. Seven
artifacts fell to edge; the eighth fell to symmetry; none was a planet.
