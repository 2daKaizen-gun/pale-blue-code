## What the completed sweep constrains

The pool was selected smallest-first, so at the *planning* floor (the fiducial 0.4% depth) its
sensitivity would span the whole planet-size range — Earth-radius on the smallest M dwarfs (R★ ~0.15)
to sub-Saturn on the largest (R★ ~1.0). But a null result is only worth the sensitivity it *actually
achieved*, curve by curve, and that is measured, not assumed (see the next section — the fiducial
overstates it).

Across all 100, every significant single event is an instrument or a systematic, each named by the
gate that caught it. Edge and symmetry carry the rejection load; baseline caught the one event that
cleared the first four gates (the sub-11-18 candidate); coherence assists twice. **Zero survive as
candidates.**

## The achieved completeness — the honest bound on the null (self-correction)

The line above ("floor ~1 R⊕ … ~7 R⊕") is the *fiducial* sensitivity — a uniform 0.4% planning depth.
The real curves are noisier than that, so the sweep's **achieved** sensitivity is coarser, and the
null is correspondingly weaker. `completeness_hunt.py` reads each star's **measured** depth floor from
its mono cache (its own curve's noise) and reports what fraction of the pool could actually have
revealed a planet at each size (`pool_assessment.pool_completeness`):

```
achieved min detectable planet:  best 0.9 R_earth · median 4.7 R_earth · worst 33.3 R_earth

stars that could have revealed a planet at or below each size:
  <=  1.25 R_earth (Earth)        :   6 of 100  ( 6%)
  <=  2.0  R_earth (super-Earth)  :  14 of 100  (14%)
  <=  4.0  R_earth (sub-Neptune)  :  39 of 100  (39%)
  <=  6.0  R_earth (Neptune)      :  54 of 100  (54%)
  <= 11.2  R_earth (Saturn)       :  77 of 100  (77%)
  <= 22.4  R_earth (2 R_jup line) :  93 of 100  (93%)
```

So the honest reading of the zero-candidate null is *not* "no Earths transit these 100 stars." Only
**6 stars** had curves clean enough to have shown an Earth-size single transit, **14** a super-Earth;
the median star bottoms out at Neptune-size (4.7 R⊕), and 7 stars were too noisy to have revealed
anything planet-size at all. The sweep firmly rules out only sub-Saturn-and-larger single transits
across most of the pool, and Earth-to-super-Earth transits on the ~1/7 of stars whose curves reached
that depth. That is the sensitivity that bounds the null — stated so the null is never read as
stronger than the data supports.

This is the expected texture of an honest single-transit hunt over quiet stars, not a failure: most
stars are quiet, loud events are almost always the telescope, and a genuine lone transit inside one
sector is rare enough that a hundred-star sweep finding none is a **null result stated completely** —
with the sensitivity that bounds it (1–7 R⊕ across the pool) written down beside it. That is what a
real search reports when it comes up empty.

## Honest boundary

Completing the sweep does not make a discovery — it establishes a clean, bounded null over one pool
of one sector. Zero candidates across 100 dwarfs is exactly what an unbiased single-transit search of
quiet stars should produce most of the time; the value is that the search is now *complete* over this
pool and its limits are written down, so the next real sky — a **new TESS sector** via the biweekly
Action, or a different pool — starts from a known, honest baseline rather than a half-finished one.
The machines miss single transits; we now know this particular patch of sky, to this depth, has none
we can defend.
