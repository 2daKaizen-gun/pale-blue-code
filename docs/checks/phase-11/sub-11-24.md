## The lever, and the question it isolates

Lever 1 (flux) is settled — PDCSAP wins (sub-11-23). Lever 2 is the detrend window. `bls._detrend`
uses a 30-day Savitzky-Golay window, fixed in sub-10-3 by **transit-depth preservation**: a window
near the transit duration follows the dip and divides it out (96% depth kept at 5 d, 82% at 2 d). But
the **noise floor** is a second, independent question. Too short a window eats long signal and adds
noise; too long a window leaves slow systematics (red noise) that raise the floor. The window that
minimises the floor need not be the one that best preserves depth, so we measured it rather than
assumed the sub-10-3 answer carries over.

## Method

`scripts/measure_detrend_floor.py` downloads each target's PDCSAP curve once (lever-1 winner), then
detrends it at 10 / 20 / 30 / 50 days through the *identical* rest of the pipeline (baseline-1 →
`sensitivity_depth_floor`) and converts each floor to the smallest planet that curve could reveal
(`sqrt(floor)·R★`, R⊕). Only the window differs. Targets: path A's 11 Earth-size stars.

small (that is *why* they are the sharpest targets), so there is little red noise for a longer or
shorter window to add or remove.

## The real finding — where the lever is *not*

Lever 2 being null is itself the signal. On these targets the detrend is not what caps sensitivity:
the floor is set by the per-point scatter over a single ~24-day sector, and no window choice changes
that. The one knob that *can* lower it is more baseline — the same star observed across several
sectors, stitched, so the noise averages down and (a bonus) a second transit could pin a period.
That is **lever 3, multi-sector stitching**, and it is where path A should spend next. Its
precondition — do these targets even *have* multiple sectors? — is the reconnaissance that opens the
next step.

## Honest boundary

- Scoped to these 11 quiet dwarfs; a noisier or brighter star, where systematics are larger, could
  show a real window dependence. The claim is about *these* targets, which are path A's actual targets.
- As in sub-11-23, this measures the **noise floor**, the completeness yardstick — not directly whether
  a given window erases a genuine long transit (a signal-recovery question for injection-recovery).
