## Scope

A monotransit gives BLS nothing to fold, so it is thrown away — and with it, the period. But the
transit we did see is not silent about the orbit. For a circular orbit crossing the star's center
(impact parameter b = 0), the transit duration `T14`, the star's mean density `rho_star`, and the
depth (through `k = sqrt(depth)`) fix the period (Winn 2010, small-angle central-transit duration):

```
T14  = (1 + k) / pi * (3*pi / (G*rho_star))^(1/3) * P^(1/3)
```

inverted to the quantity the hunt reports:

```
P_min = (pi^2 * G * rho_star / 3) * T14^3 / (1 + k)^3
```

A central transit is the **longest** transit a given period can produce; any grazing geometry
(b > 0) of the same observed duration demands a **longer** period. So b = 0 yields the shortest
period consistent with what we saw — a true **lower bound**. The survivor earns the sentence "this
orbit is at least P_min days," never "the period is P_min."

The mean density comes from the catalog radius through a main-sequence mass-radius relation
(`M ~ R^1.25`, so `rho_star / rho_sun = R^-1.75`, R in solar radii) — the same catalog-geometry
footing the sub-11-5 triage already stands on. A wrong radius, or a star that is not on the main
sequence (a subgiant is far less dense), moves the bound; that caveat travels with the number.

## The inversion is exact (round-trip)

The implemented inverse is the exact algebraic inverse of the forward central-transit relation, so
pressing a known b = 0 period through the duration and back returns it. On the best plausible
target's radius (TIC 156004112, `R_star = 0.96`, so `rho_star = 1.07 rho_sun`):

```
P = 120 d  ->  T14 = 0.4009 d  ->  P_min = 120.000000 d
```

The test asserts this to `rel=1e-9` across three (period, depth, radius) triples.

## What the bound says on a real dwarf

For the same star (`R_star = 0.96`), a single central transit implies:

```
T14 = 0.2 d  (depth 0.5%)  ->  P_min ~= 16 d
T14 = 0.4 d  (depth 1.0%)  ->  P_min ~= 119 d
T14 = 0.5 d  (depth 1.0%)  ->  P_min ~= 233 d
T14 = 0.8 d  (depth 2.0%)  ->  P_min ~= 853 d
```

This is the whole point in numbers: a transit only a few hours long around a Sun-like dwarf is
already a **hundreds-of-days** orbit — squarely the long-period ground BLS cannot fold, because
such a planet never crosses twice inside one 27-day sector. The longer the lone transit, the
longer the least period it can belong to. The bound points exactly where the hunt lives.

---

## Why it is honest

- **A lower bound, stated as one.** b = 0 gives the shortest period the observed duration allows;
  the true period can only be longer. The physics docstring, the copy, and the card all say "at
  least," never "is." A grazing transit of the same duration means a *longer* orbit, and the test
  `test_min_period_is_a_lower_bound_grazing_needs_longer` pins that direction.
- **Density from the catalog radius, caveat attached.** The bound reuses the triage's
  main-sequence footing rather than inventing a mass source. A wrong radius or an evolved star
  moves it, and that is said where the number is reported — the same honesty as the sub-11-5
  fiducial floor.
- **No radius, no bound.** A star absent from the triage, or with no radius on file, carries
  `min_period_days = None`, and the card omits the line. The tool never invents a period it
  cannot stand on — the same null discipline as an unfetched star's size verdict.

The one deliberate limit: this assumes a *circular* orbit. A real long-period planet can be
eccentric, and an eccentric transit at a fast point in its orbit is shorter than a circular one of
the same period — which would push the true period *above* even this bound. So circularity, like
b = 0, only ever makes the reported number a *floor*, never an overstatement. Both assumptions err
toward "at least."

## Honest boundary (carried forward)

The bound is only as good as the radius it rests on, and it assumes a main-sequence dwarf and a
circular, central orbit — every one of those assumptions, when wrong, makes the number a *floor*
rather than a claim, which is the direction honesty wants. What sub-11-8 does not do is turn a
survivor into a discovery: a minimum period is a property of the lone transit's *shape*, not
evidence that the dip is a planet. That still rests on the significance floor and the four
discriminators, and beyond them on the follow-up (radial velocity, imaging) the tool cannot do.
But the surface can now say the one thing that makes a single transit worth a human's attention:
this is at least an N-day world, and N is large — exactly where the machines are blind.

And still: none of the 16 plausible dwarfs is fetched yet, so no survivor with a real period
exists on the live tool today. The bound is built and tested; the sky it will describe waits on
the same single local run sub-11-7 named — `python ../scripts/fetch_plausible.py`, then watch a
plausible dwarf's first hunt. When one lands, its survivors will name their least period for the
first time.
