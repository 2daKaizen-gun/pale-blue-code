# Check: sub-11-23 — Path A, lever 1: flux choice (SAP vs PDCSAP)

**Date:** 2026-09-05
**Branch:** main
**Verdict:** PASS (the first sensitivity lever is measured, and the honest answer is *no change*:

## The lever, and the hypothesis it tested

Path A raises sensitivity by finding what actually lowers each star's measured depth floor
(`docs/vision/finding-our-own-planet.md` §9). Lever 1 is the flux column. Our fetch has always kept
SPOC's **PDCSAP** — flux the pipeline has already detrended with co-trending basis vectors (CBVs).
The hypothesis was that PDCSAP's CBV fit, tuned for short *repeating* transits, might **over-subtract
the long, lone dip of a monotransit** — the exact signal we hunt — so the raw **SAP** aperture flux,
detrended by our own Savitzky-Golay filter instead, could reach a lower floor. A real worry: we aim
at the machine's blind spot while feeding on flux the machine has already shaped.

## Method

`scripts/measure_flux_choice.py` takes each target, downloads **both** flux columns from the same
FITS (SAP is not a second download), and runs each through the *identical* pipeline —
stitch/normalize/5σ-clip → `bls._detrend` → baseline-1 → `sensitivity_depth_floor` — then converts
each floor to the smallest planet that curve could reveal (`sqrt(floor)·R★`, in R⊕). Only the flux
column differs, so any gap is the flux's doing. Targets: path A's 11 Earth-size stars (the sharpest
by achieved PDCSAP floor across sectors 103 + 105).

**SAP lowered the floor on 0 of 11; PDCSAP on 11; median Δ = −1.09 R⊕** (Δ = PDCSAP R⊕ − SAP R⊕; a
negative Δ means PDCSAP reaches the smaller planet). Switching to SAP would have cost most of these
stars their Earth-size reach. The hypothesis is reversed: on these curves the systematics still in the
SAP flux swamp the noise floor faster than our detrend can clean them, and that outweighs whatever
long-signal preservation SAP offers. PDCSAP's CBV removal is a net gain here.

## Honest boundary

- The verdict is scoped to **these targets**: small, quiet dwarfs on mostly single-sector curves —
  exactly path A's first targets, so the scope is the right one. Bright stars or long multi-sector
  baselines could tilt differently; that is a future re-measure, not a claim made here.
- What we measured is the **noise floor** (`sensitivity_depth_floor`), not directly whether PDCSAP's
  CBVs *erased a real long transit*. The floor is what our completeness map is built on, so it is the
  right yardstick for "how small a planet could this sweep have seen" — but the original worry
  (over-subtraction killing a genuine monotransit) is a *signal-recovery* question that only
  injection-recovery of long transits into SAP-vs-PDCSAP curves can fully close. Flagged for a later
  lever; it does not change today's floor result.
