## Why this, now

Path A's four sensitivity levers are all measured and null (sub-11-23/24/25, vision §9-1/§9-2): the
pipeline cannot make the eye sharper. Decision D (§9) then reframes the goal — not "we discovered a
planet," which is beyond our reach without a telescope, but "here are the quiet stars where our search
*reaches* Earth size, with the measured sensitivity and the honest disposition, in a follow-up-ready
form." Yesterday D shipped as `scripts/earth_size_dossier.py` — a terminal artifact. A goal the
product does not show is only half-adopted, so this surfaces D where a person actually looks.

## What changed

1. **`earthSizeDossier.ts`** — the pure copy layer, built from the hunt ledger the API already returns
   (`min_planet_rearth`, `depth_floor`, `disposition` per star). It selects the Earth-size-sensitive
   targets sharpest-first, counts surviving candidates, and pins the honest wording: a target has
   Earth-size *sensitivity*, never a claimed planet; "0 candidates" is a completeness statement; the
   follow-up path is named. 14 vitest cases.
2. **`EarthSizeDossier.tsx`** — thin presentation, mounted inline in `SingleTransitHunt` between the
   survivor cards and the full pool ("여기까지 우리 눈이 닿았다 — 지구크기 감도"). No extra fetch; renders
   nothing when no target reaches Earth size, so it never claims a reach the search has not measured.
3. **`FrontierVerdict.tsx`** — the residual overclaim removed. The repeated-signal frontier verdict
   read "★ 우리가 찾은 신뢰 후보 … 개척지에서 이건 드문 순간입니다"; a repeated signal is exactly what the
   automated pipelines already catch well (vision §1), so that framing overclaimed. Now: still a
   candidate, but named honestly as the machine's own territory, with confirmation left to ExoFOP/TFOP
   and false-positives called out (giants especially).

## Honest boundary

- The in-product dossier is over the **current frontier pool's** ledger (what the live hunt searched),
  not the cross-sector union the terminal script can assemble from all cached pools. Same honest
  framing, a narrower scope — the product shows what this hunt actually saw.
- This is presentation, not a new measurement. The floors and dispositions are the ones already
  computed by the search; nothing here re-derives sensitivity.
- Component render is not unit-tested (the project tests copy, not JSX, and pulls in no test-DOM
  dependency); the copy that carries every claim is fully tested, and tsc guards the wiring.
