## Why path A, and why a leaderboard first

Sectors 104, 105, and 103 are swept end to end — ~300 smallest-first dwarfs, zero candidates, every
loud dip caught by the five gates as an instrumental artefact. But the honest reading of that zero is
in the completeness: median 4–7 R⊕ across the sectors, only ~6% of curves clean enough to have shown
an Earth. Our eye sees large planets, and large single transits are largely catalogued already; the
real blind spot — a small planet's lone transit — is below where we can currently see. Sweeping more
sky at the same sensitivity would only fail to see the same small planets in more places.

So the direction turns (vision §9): stop widening, start deepening — spend effort on the *quietest*
stars and push their depth floor toward Earth size. But "quietest" must be measured, not assumed.
Stellar radius alone is a poor proxy: a small M dwarf is a sharp target only if its real curve is also
clean, and a larger star with an exceptionally quiet curve can reach Earth size too. So the first tool
ranks searched stars by the sensitivity they *actually achieved*.

## The tool

`scripts/rank_by_sensitivity.py` reads, for every searched star, the measured `depth_floor` from its
mono cache (the same valid, versioned read `completeness_hunt.py` uses — never a fetch, never a
recompute) and converts it with the star's radius into the smallest planet that curve could have
revealed: `R_planet = sqrt(depth_floor) × R_star`, in R⊕. Sorting ascending puts the sharpest curves
first. It accepts multiple pools (the mono cache is TIC-keyed, so a star shared across sectors is
ranked once). The pure `rank_by_sensitivity()` is covered by four tests (backend pytest).

## Honest boundary

- "Reaches Earth size" means the *curve was clean enough* to have shown an Earth — **not** that a planet
  is there. All 11 were searched and returned quiet / insignificant, no candidate. This is a
  sensitivity statement, nothing more.
- The floor here is *this pipeline's* floor on the existing (mostly single-sector) curves. Path A's
  actual work is to *lower* it — so that stars just past this line (1.4–1.6 R⊕: TIC 155896956, 234501204,
  292292038 …) cross into Earth range, and the 11 sharpen further.
